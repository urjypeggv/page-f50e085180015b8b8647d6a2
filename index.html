接入前该如何准备？标准工作流四步走

步骤引导 / 配置流程

01

选择适配规格

评估您日常在网设备数及月均流量开销。若是单人轻度浏览可选用基础版；若需流媒体与低延迟专线支持，则推荐进阶方案。

02

获取配置文件

在用户控制台获取专属订阅凭证或节点连接串。请确保订阅链接仅在您受信任的个人设备中载入，避免外泄导致额度受损。

03

端侧导入与分流

将配置导入相匹配的通用客户端。建议在客户端开启分流规则（如国内直连、海外代理），以此平衡网络访问速度与流量消耗。

04

连通性与并发测试

接入后先行访问常规测试站点，确认 DNS 解析无污染且节点延迟稳定，同时监测多设备同时在线状态是否处于配额限制以内。

客户端生态 / 接入说明

PC

桌面平台 (Windows / macOS / Linux)

桌面环境建议选用支持内核规则切换的图形界面应用。通过配置规则分流，可实现工作软件与日常浏览的分离加速。

  • 推荐机制：订阅链接一键拉取节点集
  • 路由模式：规则分流 (Rule-based routing)
  • 技术要求：需支持系统全局代理接口接管
MOB

移动终端 (iOS / iPadOS / Android)

移动设备核心考量在于电量损耗与蜂窝/Wi-Fi网络切换下的重连稳定性。建议开启按需连接机制以节省后台耗电。

  • 推荐机制：扫码快捷载入节点或剪贴板导入
  • 路由模式：绕过局域网及大陆常用网络地址
  • 技术要求：系统 VPN 权限配置授权
GW

网关与路由拓展 (Router / NAS)

适合多智能家居或开发测试设备集中接入的场景。在家庭或办公局域网网关部署后，内网设备无需逐一单独配置客户端。

  • 推荐机制：透明代理 (Transparent Proxy)
  • 路由模式：DNS 防污染与内网设备名单分级
  • 技术要求：需要软路由或定制固件系统支持

FAQ / 问答分类检索

主题 01

订购周期与配额消耗规则

月度流量使用完毕后，服务会如何响应？
当月流量（如基础版 100GB、旗舰版 300GB）达到上限后，节点连接将暂停出网数据转发，直到次个结账周期自动重置，或视管理后台策略选购补充数据包。
按月订阅与年付周期之间有何区别？
各版本年付均提供折让（如基础版 150元/年、旗舰版 350元/年、团队版 850元/年）。流量配额依然按自然月度逐月发放，并不支持单月透支全年额度。
主题 02

设备在线限制与多端共享机制

如何界定“同时在线设备”的数量？
系统通过短周期内与节点保持心跳连接的独立 IP 或会话凭证统计。例如基础版支持 3 台设备，若第 4 台设备发起连接，可能会触发先入设备掉线或暂时拒绝握手。
团队版 20 台设备配额可以拆分给外部人员吗？
团队版主要面向企业内聚工作团队或项目协同组。虽然支持企业定制路由与专属客户经理，但建议订阅凭据仅在受控内部成员之间流转，以防滥用造成节点被封锁。
主题 03

线路特性与网络优化机制

普通线路节点池与 IPLC 专线优化的体验差异在哪？
基础版的普通节点池依赖公共国际出口，高峰期可能因公网波动产生时延；而旗舰版配备的 IPLC 专线优化 走点对点内网穿梭，在延迟稳定性及游戏防抖动方面表现更优。
全节点原生流媒体解锁是如何实现的？
旗舰版节点配备了符合特定内容提供商区域判定的本地原生 IP 资源，降低因广播 IP 段被内容服务商批量阻断的几率，保证多平台视听体验的一致性。
